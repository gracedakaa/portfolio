# Grace Daka Portfolio

This repository contains the source for Grace Daka’s professional portfolio website.

Grace is a multilingual localization linguist and narrative specialist with experience in:

- Translation
- Transcreation
- Linguistic QA
- AI language evaluation
- Narrative and content adaptation

## What is included

The portfolio highlights:

- Professional profile and language strengths
- Services in localization, QA, and AI language work
- Verified volunteer translation projects
- Selected professional experience
- Contact information

## Translation projects

The portfolio includes verified English-to-French volunteer translation projects completed through the ProZ Bono community, with linked source and translated files in the site assets.

## Project structure

- `index.html` — main portfolio page
- `assets/` — portfolio image and downloadable project files

## Updating the site

To update the site locally:

1. Edit `index.html`
2. Add or update files in `assets/`
3. Commit and push changes to the `main` branch

## Purpose

This repository is used to present Grace Daka’s portfolio in a clean, professional format for clients, recruiters, and collaborators.
